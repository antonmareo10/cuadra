## Eligibility and originality

- 18+, eligible country (Spain is eligible; excluded: Cuba, Iran, North Korea, Syria, Russia, Belarus, Crimea/Donetsk/Luhansk, Quebec). Payment via Wise.
- The app must be **started and developed during the building period**. Existing products with Clocked bolted on are not eligible. This repository's first commit is 3 Nov 2026 and everything in it was written for the challenge.
- Libraries, frameworks, SDKs, starter templates and AI coding tools are allowed; core functionality must be created for the challenge. Credit third-party code and keep the git history.
- **Only public, synthetic or authorized data.** Every document in `data/` is synthetic and generated by `scripts/generate-documents.ts`. No real customer data.
- Never publish API keys. The key is read from `process.env.CLOCKED_API_KEY` (`.env.local`, git-ignored).

## What the entry form asks for

1. Project name and overview (what it does, who it is for, what problem it solves).
2. A demo: working app link **or** a short video of the app in use.
3. Public source repository with setup instructions and development history.
4. Which Clocked endpoints are used, how their outputs change the app, and how they work together.
5. Optional: what we learned.
6. Team members: name, email, GitHub handle.
7. Award categories to be considered for.
8. Optional public write-up (README is fine). Where relevant explain how the app handles **uncertain results, missing information and failed requests**.

## Judging

Best Overall App (100 points, averaged over four Rezolve.ai judges: CTO, CEO, CRO, Head of Applied AI):

| Criterion | Points |
|---|---|
| Practical usefulness | 25 |
| Quality of the core Clocked integration | 30 |
| Thoughtful use of additional Clocked endpoints | 15 |
| Implementation and user experience | 20 |
| Clear explanation and reproducibility | 10 |

- "Unnecessary API calls earn nothing." Additional endpoints count when they improve functionality, reliability, safety, retrieval quality or experience.
- Ties: judges discuss, most weight on integration quality.

Group awards (100 points each): depth 40, breadth 30 (10 per endpoint of the group used meaningfully), usefulness and execution 20, explanation and reproducibility 10.

| Group | Endpoints |
|---|---|
| Decide / Extract / Fill | `/decide`, `/extract`, `/fill` |
| Protect / Guard / Inspect | `/pii`, `/injection`, `/script` |
| Verify / Compare / Rerank | `/grounding`, `/compare`, `/rerank` |

"Meaningful use" = the endpoint's output changes what the app does or shows. A call whose result is ignored earns nothing.

## Prizes

Best Overall $600 · each group award $400 · People's Choice $200. **At most one judged award per project** (the higher one if it leads two) plus People's Choice: maximum $800.

## People's Choice (optional)

One public LinkedIn post with a demo or video, a link to the demo or write-up, an **active @mention of the Clocked LinkedIn page** (picked from LinkedIn's suggestions) and `#ClockedChallenge`. The post URL goes in the entry form before the deadline. Reactions 1, reposts 3, unique comments 2; entrants' own engagement does not count; no paid boosting, bots or engagement swaps.

## Credits

- Free account: 4,000 credits. Code `CLOCKEDHACKATHON` on the account page adds 16,000 (20,000 total) and raises concurrency from 1 to 4. Once per account; valid through 19 Nov 2026 (UTC). Multiple accounts = disqualification.
- One credit = 25 ms of a request's own model time (minimum 1 per request). Trial usage is valued at Production rates for reference and **charged nothing** (`X-Clocked-Cost-Basis: reference`).
- Spending is never required and does not affect judging. This app enforces a hard credit cap anyway (`CLOCKED_CREDIT_CAP`, see `lib/clocked/budget.ts`).

## API facts this app relies on

- Base URL `https://clocked.rezolve.ai/clocked`, `POST` + JSON, `Authorization: Bearer <key>`, `Idempotency-Key: <uuid>` (reuse it only to retry the identical payload).
- 3.5 MB body limit; a PDF of about 2.5 MB fits. PDFs with a text layer are read as text and every offset indexes that text (`return_text: true` returns it).
- `return_pdf: "highlight" | "redact"` writes the answer's spans back into the PDF (text mode only).
- Pipeline steps are text only; a guard step with `stop: true` ends the run when it flags the text.
- Errors: 400/422 fix input; 401/403 key; 402 credits; 409 conflict; 413 too large; 429 back off; 5xx retry with the same key unless `retryAsNew`.
- Cost headers on every response: `X-Clocked-Credits`, `X-Clocked-Cost-Usd`, `X-Clocked-Cost-Basis`, `X-Clocked-Model-Ms`, `X-Clocked-Transport` (`replay` when the ledger answered).
